# Project Materials

The [README](../README.md) introduces the finger-counting system and shows a hardware example. The [project report](PROJECT_SUMMARY.md) explains the goal, method, debugging experience, and remaining limitations.

The [hardware demonstration](VALIDATION.md) contains photographs for counts 0–5 and links to the supplied FPGA build summaries. These examples use a green cloth background.

For implementation details, see the [architecture](ARCHITECTURE.md). The [setup guide](SETUP.md) describes how to build, program, and operate the project on a DE2-115 board.

This is a collaborative undergraduate capstone. Shared contributions and inherited board-support components are described in the [team acknowledgment](AUTHORS.md) and [third-party notices](../THIRD_PARTY_NOTICES.md).
